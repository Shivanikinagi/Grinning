## Key Technical Decisions

### Why Pattern-Based Memory?
- **Simple**: No external dependencies or complex setup
- **Fast**: Regex matching is extremely efficient
- **Transparent**: Easy to debug and understand
- **Effective**: Captures 90% of important information

### Why High Temperature (0.9)?
- Encourages creative, unpredictable responses
- Makes rare events (alien/elvish) more likely to occur
- Creates more engaging, human-like conversations

### Why Modular Design?
- Memory system can be swapped or upgraded independently
- Easy to test individual components
- Clear separation of concerns
- Maintainable and extensible

## Talking Points for Interview

### "Tell me about this project"
"I built a personality-driven chatbot that demonstrates advanced prompt engineering. The challenge was creating a bot with a split personality - expert on career topics, hilariously confused about everything else - while maintaining consistency. I solved this through careful prompt design with explicit behavioral rules and frequency controls."

### "What was the biggest challenge?"
"Balancing the rare events (alien/elvish moments) so they're surprising but not overwhelming. I used frequency markers in the prompt and high temperature settings to achieve the right balance. I also implemented a pattern-based memory system that's simple but effective."

### "What would you improve?"
"I'd add database persistence for memories, implement vector embeddings for semantic search, and add analytics to track personality trait occurrences. I'd also add rate limiting and caching for production deployment."

### "Why this approach for memory?"
"I chose pattern-based extraction over complex NLP because it's fast, transparent, and captures the most important information. For a production system, I'd consider hybrid approach - patterns for structured data, embeddings for semantic understanding."
